Organización semanal

Tareas pendientes

  • Hacer los deberes.
  • Ordenar la habitación.
  • Estudiar para el examen.
  • Hacer ejercicio.
  • Preparar la mochila.

Pasos para preparar un examen

  1. Leer y comprender el temario.
  2. Organizar los temas que voy a estudiar.
  3. Hacer un resumen de cada tema.
  4. Repasar y practicar con ejercicios.
  5. Hacer un último repaso antes del examen.

Conceptos de desarrollo web

HTML
Lenguaje utilizado para estructurar el contenido de una página web.
CSS
Lenguaje utilizado para dar estilo y diseño a una página web.
JavaScript
Lenguaje de programación que permite añadir interactividad a las páginas web.
DOM
Modelo que representa la estructura de un documento HTML y permite modificarlo mediante JavaScript.
